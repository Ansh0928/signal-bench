    Run the C++ tests yourself

    This hosted report contains captured test evidence. To compile the controller and generate a fresh report, run these commands on your computer:

    git clone https://github.com/Ansh0928/signal-bench.git
cd signal-bench
make serve

    You need a C++17 compiler, Make, and Python 3.9+. Then open http://127.0.0.1:8873.
